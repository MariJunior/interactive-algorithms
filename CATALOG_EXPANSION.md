## Поведение по темам

### 1. Хеш-таблица
- **Задача:** положить ключ→значение и найти за среднее O(1).
- **Визуал:** массив бакетов; шаг hash → индекс; коллизия → цепочка (chaining).
- **Действия шагов:** `hash | place | collide | lookup | done`.
- **Sandbox:** сравнить lookup при разном load factor или chaining vs (позже) open addressing — v1: один алгоритм, sandbox optional.

### 2. Алгоритм Дейкстры
- **Задача:** кратчайшие пути из стартовой вершины во взвешенном графе без отрицательных рёбер.
- **Визуал:** граф как у BFS/DFS + таблица дистанций + «облако» необработанных вершин.
- **Действия:** `relax | extract-min | settle | done`.
- **Sandbox:** сравнить с BFS на невзвешенном срезе / или два старта — v1: page + sandbox same category `graph`.

### 3. Задача о покрытии множества (жадный)
- **Задача:** покрыть универсум минимумом подмножеств (приближение).
- **Правило:** на каждом шаге брать множество, закрывающее больше всего ещё непокрытых элементов.
- **Визуал:** универсум как чипы; кандидаты-сеты; выбранные подсвечены.
- Переиспользовать паттерн `GreedyStep` / отдельный `kind: "set-cover"`.

### 4. Задача о коммивояжёре (NP)
- **Задача:** кратчайший цикл по всем городам.
- **Учебный акцент:** полный перебор на n≤5–6 городов (показать взрыв) + жадная эвристика nearest-neighbor (не оптимум).
- **Визуал:** точки на плоскости, текущий тур, счётчик рассмотренных перестановок.
- Не обещать «решение NP» — показать, почему жадность/эвристика и почему brute force не масштабируется.

### 5. k ближайших соседей
- **Задача:** классифицировать новую точку по большинству среди k соседей.
- **Визуал:** 2D scatter двух классов; новый запрос; k окружностей/выделение соседей; голосование.
- **Параметр:** k (3/5), общий в sandbox если будет второй вариант (например, разные метрики позже).
